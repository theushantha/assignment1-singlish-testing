# Test Automation

Short project to run test automation scripts.

## Prerequisites
- Python 3.8 or newer
- (Optional) Create and activate a virtual environment:

  python -m venv .venv
  source .venv/bin/activate

## Install

If you have a `requirements.txt`, install dependencies:

  pip install -r requirements.txt

## Run

To run the main script:

  python test_automation.py

## Notes
- Place any test files or configs alongside `test_automation.py`.
- Open an issue if you need additional setup instructions.
